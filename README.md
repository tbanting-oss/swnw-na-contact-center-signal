# SWNW Signal — North America Contact Center Market

Static hosting for the SWNW Signal page on the North America contact center
market (CCaaS and on-premises, 2025 estimate).

Single-file: the entire page — HTML, CSS and content — is in `index.html`.
No build step, no framework. Inter is loaded from Google Fonts; everything
else is inline.

Hosted via GitHub Pages from `main` / root.
